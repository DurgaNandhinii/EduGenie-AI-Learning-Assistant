# Project Planning Phase

## Milestones & Timeline

| Milestone | Activities | Deliverable |
|---|---|---|
| **Milestone 1: Model Selection & Architecture** | Select AI models (Gemini for reasoning tasks); design folder architecture | Project skeleton with all module files created |
| **Milestone 2: Core Functionalities Development** | Implement all 5 modules (Explanation, Q&A, Quiz, Summary, Learning Path); build FastAPI endpoints for each | Working backend with all 5 REST endpoints functional |
| **Milestone 3: Frontend Development** | Build HTML form with tabs for each feature; style with CSS; connect frontend to backend via fetch API | Fully interactive web UI |
| **Milestone 4: Deployment** | Run locally with Uvicorn; conduct functional testing of all 5 features | Working, tested application accessible via browser |

## Tools & Technologies Used
- **Backend:** FastAPI, Uvicorn, Jinja2
- **AI/LLM:** Google Gemini API (`google-generativeai` SDK)
- **Frontend:** HTML, CSS, vanilla JavaScript
- **Environment management:** python-dotenv, virtual environments
- **Version control:** Git & GitHub

## Task Ownership
Solo project — all phases (design, development, testing, documentation)
completed individually.
